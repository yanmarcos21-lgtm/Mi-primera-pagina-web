1. Parte Teórica

1.1 ¿Qué es HTML y cuál es su función en la web?

HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para crear y estructurar el contenido de las páginas web.

Permite organizar:

- Textos
- Imágenes
- Enlaces
- Tablas
- Formularios
- Videos
- Otros elementos web

Su función principal es definir la estructura y el contenido de una página web para que los navegadores puedan interpretarla y mostrarla correctamente.

1.2 ¿Qué es una etiqueta HTML?

Una etiqueta HTML es un elemento utilizado para indicar al navegador qué tipo de contenido se está colocando en una página web.

Algunas etiquetas comunes son:

<html>
<head>
<title>
<body>
<h1> a <h6>
<p>
<a>
<img>
<ul>
<ol>
<li>
<div>
<form>
…
